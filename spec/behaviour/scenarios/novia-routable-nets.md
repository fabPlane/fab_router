# Scenario: connections routable with vias disabled (`novia`)

_generated by running both baseline routers as sealed programs on the board with the stated settings and recording what each produced: `viasAllowed: false`, `maxPasses: 100`, optimiser on, fanout off, wall-clock budget 120 s per run (reference A) / 60 s routing budget (reference B), single thread._

Required outcome, for every board below, when `route()` runs with `viasAllowed: false` (all other
settings at their defaults, `maxPasses ≥ 100`, `timeoutSeconds ≥ 120`):

1. No Barrel is added (`report.added.barrels = 0`, contract R-1..R-5); Barrels already in the file stay.
2. Every net listed under **complete in both** ends with `incomplete = 0` for that net
   (`report.perNet` / `checkDrc().incompletes`): each of its connections is realised by Tracks on a
   single Sheet (or through Barrels the file already contained).
3. `violationsAdded = 0`.

The counts are what each reference achieved and are advisory bounds: an implementation whose
`incompleteAfter` exceeds the larger of the two reference numbers is weaker than both references on
that board. Nets under **incomplete in both** are connections neither reference could complete
on one Sheet; nothing is required of them. Nets that only one reference completed are not listed.
